정원 온라인 기도회

매주 월~목 · 밤 10:00~10:20

하나님의 사랑하시는 자, 여디디야가 함께 기도하며 자라는 정원입니다.
성경봉독 → 찬양 → 기도 순서로, 짧지만 깊게 모입니다.

정원은 마이크를 끄고(음소거) 입장하는 것이 기본 약속이에요
참여하는 법
1
밤 9시 55분, 앱을 열어요
정원 탭의 “정원 입장” 버튼을 누르면 구글미트로 바로 연결됩니다. 입장 화면(그린룸)에서 마이크를 꼭 끄고(음소거) 들어와 주세요 — 다 같이 조용히 시작합니다. 인도자는 미리 들어와 준비합니다.
2
함께 기도해요 (10:00~10:20)
성경봉독으로 문을 열고, 찬양을 들으며 마음을 모으고, 함께 기도합니다. 20분, 부담 없이 깊게.
3
참여 체크 & 기도제목
정원 탭에서 참여 체크 한 번이면 기록됩니다. 나누고 싶은 기도제목이 있으면 함께 적어주세요(선택).
인도자라면
9시 55분까지 입장 준비
로테이션 순서에 따라 그날의 인도자가 먼저 들어와 회의를 엽니다.
찬양은 “탭 공유 + 오디오 공유”
화면 공유 시 Chrome ‘탭’을 선택하고 ‘오디오 공유’에 체크해야 찬양 소리가 함께 전달됩니다. (창·전체화면 공유는 소리가 안 나갑니다)
마칠 때는 “통화 종료” 말고 “나가기”
“통화 종료”를 누르면 다음 날 입장이 막힐 수 있어요. 꼭 “나가기”로만 빠져주세요.
알림 받기 (홈 화면에 설치)
기도회 시작 5분 전(밤 9:55) 알림을 받으려면, 앱을 홈 화면에 추가한 뒤 정원 탭에서 “알림 켜기”를 눌러주세요. 아이폰은 홈 화면에 추가해야만 알림이 작동합니다.
아이폰
Safari 하단 공유 버튼 → “홈 화면에 추가” → 홈 화면의 정원 아이콘으로 앱을 열고 알림 켜기.
안드로이드
Chrome 메뉴(⋮) → “홈 화면에 추가” 또는 설치 안내 → 앱을 열고 알림 켜기.

소리·진동이 안 울릴 때

알림은 도착하는데 소리·진동만 없다면 폰의 앱 알림 설정 때문이에요. 웹앱이라 이 화면을 자동으로 열어드릴 수 없어, 아래 위치로 직접 가서 켜주세요.

아이폰
설정 → 알림 → 정원X여기갑세 → ‘소리’와 ‘햅틱(진동)’ 켜기.
측면 무음 스위치·집중 모드(방해금지)도 확인하세요.
안드로이드
설정 → 앱 → 정원X여기갑세 → 알림 → 해당 알림의 소리·진동 켜기(또는 중요도 ‘높음’).
무음·방해금지 모드도 확인하세요.
벨소리 모드면 소리, 무음 모드면 진동만 — 카톡 알림과 동일한 방식입니다.
